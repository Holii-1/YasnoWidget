# ⚡️ Yasno Widget for macOS

> Нативний віджет для робочого столу, системної панелі віджетів macOS (`WidgetKit`) та верхньої панелі (`Menu Bar`) для моніторингу графіків стабілізаційних/екстрених відключень **Yasno / ДТЕК** у поєднанні з живими датчиками **СвітлоБот** та **Healthchecks.io (ESP32)**.

---

## 📸 Основні можливості

### 1. 🖥 Верхня панель (Menu Bar) — Дефолтний та Компактний режими
Підтримує перемикання між двома стилями відображення (у Налаштуваннях або через ПКМ у топбарі):
- **Дефолтний режим:**
  - `🟢 Вимкнуть: 14:00 (1г 20хв)` — коли світло є, показує час наступного планового вимкнення та зворотний відлік.
  - `🔴 Увімкнуть: 18:00 (2г 15хв)` — коли світла немає, показує очікуваний час увімкнення.
- **Компактний режим (спеціально для MacBook з «чолкою» / Notch):**
  - `🟢 14:00 (1г 20хв)` або `🟢 14:00` — мінімальна ширина в меню-барі.
  - `🔴 18:00 (2г 15хв)` або `🔴 18:00`.
- **Попередження за 15 хв:** `⚠️ 14:00 (12хв)` — автоматичне підсвічування помаранчевим кольором та системне Push-сповіщення за 15 хвилин до відключення.
- **Аварійні відключення:** `🚨 Екстрені відключення` / `🚨 Аварія`.

### 2. 📡 Живі датчики світла: СвітлоБот та Healthchecks.io (ESP32)
Для кожного пресету («Дім», «Офіс» тощо) можна підключити реальний датчик наявності напруги 220V:
- **СвітлоБот (`svitlobot.in.ua`):**
  - Підключення за назвою публічного Telegram-каналу вашого будинку (напр. `@svitlo_...` або `t.me/...`) — без жодних ключів чи авторизації, або за персональним `channel_key`.
  - **✨ Розумне автовизначення черги (всі 60 груп Yasno):** застосунок автоматично розпізнає чергу відключень (групи `1.1` – `60.4`) з опису каналу, закріплених повідомлень, назви вулиці/адреси в заголовку або за співставленням графіків публікацій і одразу встановлює її для профілю.
- **Healthchecks.io (для ESP32 / роутерів):**
  - Підключення за **Read-Only API Key** (автоматично зчитує поточний стан, час останнього пінгу з точністю до секунди та історію перемикань `/flips/` через `unique_key` або `uuid`).
  - Підтримка фільтрації конкретного датчика у форматі `API_KEY:назва_або_slug`, а також підтримка **Badge URL** (`.json` / `.svg`).
  - Вбудований захист від випадкової вставки ping-посилання `hc-ping.com` (щоб Mac не генерував хибні пінги замість ESP32).
- **🔔 Фоновий моніторинг та сповіщення для ВСІХ доданих профілів:**
  - Навіть якщо віджет перемкнуто на «Дім», застосунок у фоні продовжує опитувати датчики для «Офісу» чи інших збережених адрес і миттєво сповіщає про зміну живлення (`🟢 [Офіс] Світло з'явилося!`, `🔴 [Дім] Світло зникло!`).
  - Персональні попередження за 15 хв до відключення для кожної збереженої адреси.
  - Кнопка швидкої перевірки доставки сповіщень у Налаштуваннях.

### 3. 📊 Розумна корекція 24-годинної смуги та графіка «За фактом»
Коли підключено **СвітлоБот** або **Healthchecks.io**:
- **Минула частина доби (`00:00 → поточна хвилина`)** на 24-годинній смузі та у списку слотів знизу автоматично перебудовується за **реальними даними датчика**:
  - Наприклад, якщо за графіком світла не мало бути з `06:00 до 10:00` (4 год), але реально його вимикали лише з `08:00 до 09:00` (1 год) — на смузі та в списку слотів відобразиться лише **`08:00 – 09:00 [ФАКТ] 1 год`**, а `06:00–08:00` та `09:00–10:00` стануть зеленими.
- **Індикація під час активного планового слоту (`МОЖЛИВО`):** якщо зараз триває плановий слот відключення (наприклад, `08:00–12:00`), але о `09:00` дали світло — інтервал `08:00–09:00` стає червоним (`[ФАКТ]`), а поточне вікно зі світлом `09:00–12:00` підсвічується **помаранчевим (`[МОЖЛИВО]`)** (світло зараз є, але за графіком можуть знову вимкнути). Після завершення слоту о `12:00` (або при повторному вимкненні) вся смуга автоматично фіксується за фактом (наприклад, `09:00–11:00` зеленим і `11:00–12:00` червоним).
- **Позапланові відключення у «зеленій зоні»:** якщо за графіком з `10:00 до 13:00` має бути світло, але фактично його немає — минула частина слоту без світла одразу стає **червоною (`[ФАКТ]`)**, залишок поточного слоту до `13:00` підсвічується **помаранчевим (`[МОЖЛИВО]`)**, а таймер у шапці та топбарі замість хибного «Вимкнення о 13:00» показує **`Поза графіком (слот до 13:00) • Очікується увімкнення`** (або час кінця наступного планового слоту, якщо світло вимкнули на 15–30 хв раніше графіка).
- **Фільтр мікро-обривів роутера:** короткі перебої зв'язку `< 2 хв` (перезавантаження роутера) ігноруються і не спотворюють графік.

### 4. 🏠 Пресети, пошук за адресою та системні віджети macOS
- **Пресети (Закладки):** швидке перемикання між локаціями (`Дім`, `Офіс`, `Батьки`) у шапці віджета, на системному віджеті macOS та через меню топбара. Повне редагування назви, черги (`Picker`) та датчика для кожного пресету.
- **Пошук черги за адресою:** вбудований пошук вулиці та реального номера будинку через базу Yasno (`v2 API`) з автоматичним визначенням черги.
- **Синхронізація з системними віджетами macOS (`WidgetKit`):** підтримка малих, середніх та великих віджетів на робочому столі macOS з інтерактивним перемиканням пресетів та днів (`Сьогодні` / `Завтра`).
- **🚀 Автозапуск при старті Mac:** керування через нативний `SMAppService` прямо з налаштувань.

## 🛠 Встановлення та керування

### Встановлення або оновлення (1 команда)
```bash
./install.sh
```

### Скрипти в репозиторії
- **`./install.sh`** — компілює основний застосунок і розширення `WidgetKit`, підписує з App Group entitlements, встановлює у `/Applications/Yasno.app` та запускає.
- **`./restart.sh`** — перезапускає програму та оновлює системні віджети.
- **`./uninstall.sh`** — повністю видаляє програму, системні віджети, кеш та збережені налаштування.
